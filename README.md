# Campus Quest Cove

Design a complete, polished web application UI for "Campus Connect", a student community platform for asking academic questions, sharing knowledge, and finding teammates for projects and hackathons.

Product Features

The application has two main features:

Ask & Answer: Students post questions, receive peer explanations, upvote useful answers, and explore a searchable knowledge feed.

Find Teammates: Students publish project recruitment posts, discover people with complementary skills, and express interest in joining teams.

Users first encounter a login or sign-up screen. After authentication, they enter the main dashboard.

Visual Direction: Modern Pixel Art

Create a distinctive pixel-art-inspired interface that combines retro gaming aesthetics with the usability of a modern web application.

Use:

Carefully designed pixel-art icons, avatars, and decorative illustrations.

A limited retro-inspired palette of deep navy, cream, mint green, and vibrant orange.

Pixel-inspired headings paired with highly readable body typography.

Crisp outlines, subtle retro borders, and carefully aligned grid layouts.

Small pixel-art campus buildings, computers, books, stars, and collaborative characters.

Subtle retro interface details without overwhelming the content.

Use pixel art as a visual identity, not as an excuse to make the interface difficult to use. Body text, forms, question descriptions, and navigation must remain clean and readable.

Dashboard Layout

Create a modern dashboard with a persistent sidebar containing Home, Ask & Answer, Find Teammates, My Activity, Saved Posts, and Profile.

The main dashboard should feature:

A welcome message: "Level up your campus connections."

A searchable discovery bar.

Two prominent feature panels: "Ask the Community" and "Build Your Team".

Recent questions with subject tags, author avatars, answer counts, and upvote buttons.

Recruitment cards showing project titles, required skills, open positions, and team details.

A prominent "Create Post" button.

Ask & Answer

Create a question feed with topic filters, searchable questions, readable discussion cards, answer counts, and upvote controls. Use small pixel-art icons to distinguish subjects and helpful answers.

Find Teammates

Create a project discovery feed with skill tags, project categories, role requirements, recruitment status, and "Express Interest" buttons. Use small pixel-art illustrations to represent collaboration and teamwork.

Authentication

Design coordinated login and sign-up screens with a pixel-art campus illustration, a welcoming headline, accessible forms, and clear authentication buttons.

Design Constraints

Maintain strong information hierarchy, consistent spacing, responsive layouts, and accessible contrast. Keep pixel artwork crisp and intentional.

Avoid making the entire interface resemble a retro game screen. The result should be a usable student platform with pixel-art branding, not a game HUD.

Generate a cohesive, high-fidelity design system across authentication, dashboard, question feeds, question details, teammate discovery, recruitment forms, and profiles.
